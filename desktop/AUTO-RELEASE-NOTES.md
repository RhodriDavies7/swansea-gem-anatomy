Offline anatomy revision with the latest committed model data and images.

Downloads:
- **Apple Silicon Mac:** `arm64.dmg`
- **Intel Mac:** `x64.dmg`
- **Windows 10/11 (64-bit):** `Setup-…-x64.exe`

Install the new version to receive the latest content. Existing desktop installations do not update automatically. Locally saved ratings and spaced-repetition progress remain separate from the installation and survive updates. Export a progress backup from Review & progress for an additional copy.

Includes model/section-specific image revision, combined image and knowledge sessions, anatomy filters, and progress by model/system/region. For sectional photos, assign “Section pictured” in the local image portal before publishing.

Mac packages are ad-hoc signed and verified, but not Apple-notarized. Windows installers are unsigned: Smart App Control may block them. This release does not add trusted publisher signing.

Built automatically from the linked commit after tests and all three platform builds pass. SHA256SUMS.txt lists installer checksums.
